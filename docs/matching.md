# 音源匹配算法速览

> 本文由原 README「匹配算法速览」章节迁出。完整算法细节见 [设计要点](design-notes.md) 第 8、10、11 条。

四阶段流水线：

```
Stage 1 候选召回（三路查询）
  ↓
Stage 2 硬过滤（标题黑名单 + 时长粗筛）
  ↓
Stage 3 精确校验（详情接口 + 分P定位，经 enrichTopK 预筛）
  ↓
Stage 4 六维加权打分
```

标定后权重：

| 维度     | 权重   |
| ------ | ---- |
| 标题歌手匹配 | 0.30 |
| 时长吻合度  | 0.30 |
| UP主可信度 | 0.19 |
| 分区与标签  | 0.08 |
| 文本规范度  | 0.07 |
| 发布先验   | 0.06 |

阈值：`AUTO ≥ 0.82`，`REVIEW ≥ 0.62`；点播场景 REVIEW 候选激活底线 `0.60`（见设计要点 11）。

> **关键结论**：标题（0.30）+ 时长（0.30）构成两个独立强信号的交叉验证。
> 翻唱必须靠 Stage 2 的标题黑名单拦截 —— 打分层拦不住（仿真中翻唱得分 0.686，与真阳性区间重叠）。
